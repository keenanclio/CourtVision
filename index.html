Sistem Bird's-Eye View Tracker Lapangan Basket

Mendeteksi pemain dari kamera HP dan mentransformasikannya menjadi tampilan coaching board 2D secara live streaming.

Latar Belakang Proyek

Proyek ini dikembangkan untuk memudahkan analisis strategi dalam olahraga bola basket. Dengan merekam lapangan dari sisi atas menggunakan kamera HP (DroidCam), sistem "Bird's-Eye View Tracker" memproses video untuk mendeteksi pemain. Melalui transformasi matriks, posisi pemain diproyeksikan ke dalam map 2D lurus dari atas secara real-time untuk evaluasi pergerakan yang lebih akurat.
